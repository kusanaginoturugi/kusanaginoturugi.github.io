プライバシーポリシー（rclone 個人用クライアント）

最終更新: 2026-11-11

この OAuth クライアント「rclone」は、kusanaginoturugi 本人が自分の Google Drive にファイルを保存するためだけに使います。

アクセスする Google ユーザーデータ

権限は drive.file だけです。rclone が作成したファイルとフォルダの作成、一覧、読み出し、更新にだけ使います。それ以外の Drive のファイルにはアクセスしません。

収集・保存・共有

  • 運営者のサーバーはなく、個人情報を収集しません。
  • 認証トークンは、利用者自身のパソコンにある rclone の設定ファイルにだけ保存されます。
  • Google ユーザーデータを第三者に提供・販売せず、広告や機械学習の学習には使いません。
  • Google API から受け取った情報の利用は、Limited Use の要件を含む Google API Services User Data Policy に従います。

アクセスの取り消し

Google アカウントのサードパーティ接続から、いつでもこのアプリの許可を取り消せます。

English

This OAuth client "rclone" is used only by its owner, kusanaginoturugi, to store files in the owner's own Google Drive. It requests only the drive.file scope and uses it solely to create, list, read and update files and folders that rclone created. There is no server and no personal data is collected. OAuth tokens are stored only in the rclone configuration file on the user's own computer. Google user data is never sold, shared with third parties, or used for advertising or machine-learning training. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/connections. Contact: https://github.com/kusanaginoturugi
